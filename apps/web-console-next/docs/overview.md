# web-console-next

Next.js 15 + opennextjs/cloudflare delivery of the Kuyil web console (per-environment, Workers + Static Assets)

The kuyil console UI — Next.js compiled to a Cloudflare Worker with
Static Assets, configured against the API edge. Public at
`https://kuyil-web-console-next-{stage,prod}.vijayakrishnan12994.workers.dev`.

## Depends on

- **api-edge** — Cloudflare Worker for the API edge Runtime
